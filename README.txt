JANITHA RATHNAYAKA - PORTFOLIO WEBSITE

Files:
- index.html: website structure
- style.css: visual design
- config.js: Supabase URL and publishable key
- app.js: database and authentication functions

IMPORTANT:
1. This ZIP contains the website source files.
2. A ZIP file is not a live website; hosting is required.
3. Your Supabase project must have correctly configured
   'projects' and 'contact_messages' tables.
4. Configure Row Level Security policies carefully.
5. The publishable key can be used in frontend code.
   Never put a service-role or secret key in frontend code.
6. Do not publicly expose contact messages.
7. For ES modules, test using a local web server or host the
   website on a static hosting service; file:// may not work.
